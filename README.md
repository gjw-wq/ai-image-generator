# AI 图片生成器

基于智谱 AI CogView-3 的文生图 Web 应用。输入一句描述，选择尺寸与风格，即可生成图片；内置提示词优化（glm-4-flash），历史记录保存在本地，支持查看大图与下载。

## 功能

- 多行文本框输入图片描述
- 尺寸三选一：1024x1024 方形 / 768x1344 竖版 / 864x1152 海报
- 风格五选一：写实 / 卡通 / 油画 / 水彩 / 赛博朋克，选定后自动把风格关键词追加进提示词
- 优化提示词：调用对话模型把简单描述扩展为包含主体、环境、光线、色彩、构图、质量词的详细英文提示词并回填
- 生成图片：期间显示加载动画与"通常需要 10~30 秒"提示，成功后展示图片
- 下载图片：保存为 ai-image-<时间戳>.png
- 历史记录侧栏：LocalStorage 保存提示词、尺寸、图片 URL 与时间；缩略图 + 提示词；点击查看大图；可删除；链接失效时显示占位提示
- 全流程中文友好错误提示

## 技术栈

React 18 + TypeScript + Vite 5 + Tailwind CSS 3，无额外运行时依赖。

## 获取智谱 API Key

1. 访问智谱 AI 开放平台：https://bigmodel.cn
2. 注册并登录，进入控制台
3. 在「API Key」页面创建并复制你的 Key

## 配置环境变量

复制 `.env.example` 为 `.env.local`，填入你的 Key：

```
VITE_ZHIPU_API_KEY=你的智谱APIKey
```

> 注意：`.env.local` 已被 .gitignore 忽略，不要把 Key 提交到代码仓库。

## 启动步骤

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 http://localhost:5173）即可使用。

构建生产版本：`npm run build`，本地预览：`npm run preview`。

## 注意事项

1. **图片 URL 有时效**：智谱返回的图片链接会在一段时间后失效，请生成后及时下载保存；历史记录中的旧图可能显示"链接已失效"，属正常现象。
2. **跨域代理**：浏览器直连智谱接口会被 CORS 拦截，本项目通过 Vite 开发代理将 `/api` 转发到 https://open.bigmodel.cn，因此必须以 `npm run dev` 方式访问；生产部署需自建同源转发服务。
3. **成本控制**：图片生成按量计费（cogview-3），请留意智谱平台额度，避免频繁重试；提示词优化使用免费的 glm-4-flash。
4. **API Key 安全**：Key 仅配置在本地 .env.local 中，用于开发调试，切勿提交或分享。
